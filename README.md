# Portfolio Website

Live site: https://tussor.github.io/test/

## Editing and publishing the site

1. Double-click **`Edit Site.bat`** (or its desktop shortcut).
   A black window opens and the editor opens in your browser.
   **Leave the black window open while you edit.** Closing it stops the editor.
2. Click **✎ Edit Mode** in the bottom-right corner.
3. Make your changes:
   - **Text:** click any text and type.
   - **Images:** click the camera icon on an image to upload a photo. If the card already has an image, the new one is added to its gallery. Drag the image to reposition it, and use the slider to zoom.
   - **Tags:** click **+ tag** to add a tag and **×** to remove one.
   - **Cards:** use the **+** tiles to add works, showcase items or categories, and the red **×** to remove them.
   - **Category:** pick a work's category from the dropdown next to its label.
4. Click **🚀 Publish**. When you see **✓ Published!**, the live site updates within 1–2 minutes.

Your edits are saved automatically in the browser as you work, so nothing is lost if you close the tab before publishing.
To throw away everything since the last publish, click **Reset** twice.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| "Is the black panel window still open?" | Double-click `Edit Site.bat` again, then click Publish again. |
| Publishing failed at step "push" or "pull" | Check your internet connection and try again. If it keeps failing, send a screenshot of the black window to your developer. |
| A GitHub sign-in window appears | Sign in once with your GitHub account. You won't be asked again. |
| The live site still shows the old version | Wait 2 minutes, then refresh with **Ctrl + F5**. |

## For developers

- `index.html`: the public site (generated by Publish, don't edit it by hand while the client is editing).
- `editor.html`: the site plus the inline builder.
- `panel/`: local edit and publish server. See [`panel/README.md`](panel/README.md) for setup on the client's computer.
- `assets/works/`: work images.
- `DESIGN.md`: design notes.
